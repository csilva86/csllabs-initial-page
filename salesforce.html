Project 01

Salesforce · Claude Code · Python · GitHub

Org Assessment

Does a Salesforce org meet what the business asked for? Org Assessment answers with evidence and documents the org along the way, without ever changing it. Claude Code subagents read the org in parallel, and Python checks compare what they found with the client's requirements.

What it does

  • Translate business rules into technical checks: an agent drafts them, the consultant approves.
  • Collect licenses, permissions, objects, automations and limits in parallel, into a dated snapshot.
  • Check every requirement as met, partial or not met, each with the evidence that proves it.
  • Report in two voices: a summary in business language for the client, and the detail with a recommended fix for the consultant (HTML and PDF).
  • Document the org: data dictionary, permission matrix, automation map, licenses and limits.
  • Learn from each project: a second brain keeps anonymised patterns for the next one.

Guardrails, enforced by code

  • Read-only. A Claude Code hook allows only read-only Salesforce CLI commands and blocks everything else.
  • Client data stays home. Snapshots and reports never reach git, and patterns are scanned for client data before they are saved.
  • A person approves. No check runs and no pattern is kept without the consultant's approval.

Under the hood

  • Same snapshot, same result: AI handles only the judgement calls, and those are labelled.
  • Over 170 automated tests cover the guardrails, collection, checks, reports and documentation.
  • Tested end to end on a real org: two access gaps found, fixed and proven closed with a before/after run.

Project 02

Salesforce · Apex · GitHub

DigiLibrary

A Salesforce app for managing a corporate digital library: which books exist, how many copies are available and who has one on loan. Built for an Apex developer challenge, with an extra integration with the public Open Library API.

What it does

  • Search by title or author in the library catalogue and on Open Library at the same time.
  • Import a book found only on Open Library into the catalogue with one click.
  • Loan any book with a copy available. With no copies left, the request fails with a clear message.
  • Follow the catalogue and the active loans in two live lists on the Home page.
  • Return a book by deleting its loan: the copy goes back into circulation right away.

Under the hood

  • Each book keeps its total and available copies, correct even when many loans are created or removed in one batch.
  • The loan limit is enforced on the server, so the interface cannot bypass it.
  • If Open Library is slow or offline, search keeps working with the local catalogue.
