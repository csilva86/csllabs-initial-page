Salesforce · Apex · GitHub

DigiLibrary

A Salesforce app for managing a corporate digital library: which books exist, how many copies are available and who has one on loan. Built for an Apex developer challenge, with an extra integration with the public Open Library API.

What it does

  • Search by title or author in the library catalogue and on Open Library at the same time.
  • Import a book found only on Open Library into the catalogue with one click.
  • Loan any book with a copy available. With no copies left, the request fails with a clear message.
  • Follow the catalogue and the active loans in two live lists on the Home page.
  • Return a book by deleting its loan: the copy goes back into circulation right away.

Under the hood

  • Each book keeps its total and available copies, correct even when many loans are created or removed in one batch.
  • The loan limit is enforced on the server, so the interface cannot bypass it.
  • If Open Library is slow or offline, search keeps working with the local catalogue.
